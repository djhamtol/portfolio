SKILLS

* 연한 카드는 기본적인 툴 사용법만 익힌 알파 스킬입니다.

HTML5
시맨틱 태그를 활용하고, 웹 접근성과 웹 표준을 준수하여 의미 있는 마크업을 구현합니다.
CSS3
Flex, Grid, Position 등을 활용해 레이아웃을 구현하고 반응형 웹을 제작합니다. CSS 변수와 재사용 가능한 스타일을 활용해 유지보수성을 높입니다.
JavaScript
DOM과 이벤트를 활용해 인터랙션을 구현하고, 함수화를 통해 코드를 효율적으로 구성합니다.
jQuery
DOM과 이벤트를 활용해 jQuery 기반 웹 페이지를 구현합니다.
Swiper
기본 구조를 이해하고 옵션을 활용해 다양한 커스텀 슬라이드를 제작합니다.
GSAP
GSAP 기본 문법과 ScrollTrigger를 활용해 스크롤 애니메이션과 인터랙션을 구현합니다. Flip을 활용한 요소의 위치 및 크기 전환을 경험했습니다.
day.js · Flatpickr · Litepicker
Day.js를 활용한 날짜 데이터 처리와 Flatpickr 등 Date Picker 라이브러리를 활용해 날짜 선택 UI를 구현합니다.
i18next
JSON 기반의 언어 데이터를 구성하고, key와 data-i18n 속성을 연결해 다국어 지원 기능을 구현합니다.
GitHub
Git을 활용해 버전을 관리하고 GitHub를 통해 프로젝트를 관리하며 배포합니다. 팀 프로젝트를 진행해 협업한 경험이 있습니다.
Notion
프로젝트 진행 과정과 학습 내용을 정리합니다. 플래너를 만들어 무료 배포한 경험이 있습니다.
Figma
기본 사용법을 익혀 포트폴리오 사이트의 와이어프레임을 제작했습니다.

Q&A

  • 1. 디자인 결과물은 없나요?
  • 2. 작업물을 만들면서 특별히 느낀 점이 있나요?
  • 3. 직무와 관련해서 앞으로 어떤 것을 더 공부하고 싶나요?
  • 4. AI를 어떻게 생각하시나요?

현재는 디자이너보다는 퍼블리셔, 나아가 프론트엔드 개발자로 성장하기 위해 코딩 공부에 집중하고 있습니다. 다만 업무상 필요하다면 간단한 디자인 업무 정도는 해낼 수 있도록 배우고 노력하겠습니다. 결과물은 없지만 과거 Photoshop, Illustrator, Premiere Pro, After Effects를 독학한 경험이 있으며, Figma는 강의를 통해 학습하여 포트폴리오 사이트의 와이어프레임을 직접 제작했습니다.

다양한 버그 케이스를 고려해야 하는 것이 어려웠는데, 자주 발생하는 문제를 학습하고 경험을 쌓아 완성도 높은 화면을 만들 수 있도록 연습해야겠다고 느꼈습니다. 또한 무조건 구현하는 것이 실력 있는 퍼블리셔라고 생각했는데 작업을 진행하며 성능과 유지보수, 협업의 중요성을 배웠습니다. 특히 협업 과정에서 조율이 필요한 부분을 판단하고, 상대방이 이해하기 쉽게 설명하는 능력을 기르고 싶다고 생각했습니다.

React와 Sass를 학습하며 변화하는 개발 시장의 흐름에 맞춰 역량을 넓히고 싶습니다. 직접 프로젝트에 적용하며 각 기술의 장점을 경험하고, 라이브러리 사용뿐만 아니라 필요한 기능을 직접 구현해보며 차이를 이해하고자 합니다. 현재 포트폴리오 사이트에서도 슬라이드 라이브러리 없이 직접 구현하는 등 다양한 시도를 하고 있습니다. 라이브러리 활용 능력과 함께 기본 원리를 이해하는 개발자가 되고 싶습니다.

퍼블리싱을 독학하며 AI에게 수많은 질문을 하면서 장점과 한계를 직접 경험했습니다. AI는 코드를 빠르게 제안하지만 적절하지 않은 방법도 제시합니다. AI가 복잡한 JavaScript만 제시하는 상황에서 시안을 약간만 변경해 CSS만으로 해결한 경험도 있습니다. 프롬프트만으로 판단하는 AI와 달리 사람은 전체적인 상황을 고려해 적절한 방법을 선택할 수 있다고 생각합니다. 직접 구현하고 고민하며 판단력을 키워 AI를 하나의 기술로 활용하고 싶습니다.
